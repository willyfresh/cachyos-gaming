# Keybinds

Super-key (Windows key) chords on three machines. A combo is listed if
**any** of the three binds it. `—` means that machine leaves it alone.

| Column | Machine |
|--------|---------|
| **Windows** | Windows 11, [Microsoft’s list](https://support.microsoft.com/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec) |
| **Novalis** | This CachyOS Hyprland box (`configs/hypr/hyprland.lua`) |
| **Delorean** | ThinkPad Omarchy + overlay (`omarchy-delorean`). Overlay wins; everything else is live Omarchy stock |

Modifier order per letter: Super, Shift, Ctrl, Alt, then the doubles, then all three.

Already the same job: Super+Space launcher (Start-adjacent),
Super+E files, Super+L lock, Super+V clipboard, Super+Q close
(Windows’ Super+Q is Search).

## Arrows

Novalis: Super focuses, and Up/Down at the edge change to the previous
or next occupied workspace on this screen. Shift moves, and Shift+Up/Down
at the edge carry the window onto the neighboring workspace number,
including an empty one. The step stops at 1 and at 10. Left and right
stay on this workspace. Ctrl+Left and Ctrl+Right move every screen to
the previous or next workspace number, including an empty one, and stop
at 1 and at 10. Ctrl+Up, Ctrl+Down, Alt+arrow, and Ctrl+Alt+arrow stay
unbound. Size is Super+/- .
Delorean: Super = focus then next occupied desk, Shift = move to adjacent
numbered desk, Ctrl = swap on this desk.

| Key | Windows | Novalis | Delorean |
|-----|---------|------|----------|
| Super+Left/Right | Snap half-screen | Focus that way | Focus, then occupied desk |
| Super+Up | Maximize | Focus up, or previous occupied workspace | Focus, then occupied desk |
| Super+Down | Restore / minimize | Focus down, or next occupied workspace | Focus, then occupied desk |
| Super+Shift+Left/Right | Move window to monitor | Move the window that way | Move window to adjacent desk 1–10 |
| Super+Shift+Up/Down | Maximize / restore vertically | Move that way, or onto the neighboring workspace | Move window to adjacent desk 1–10 |
| Super+Ctrl+arrows | Switch virtual desktop (L/R) | Left/Right: previous or next number on every screen | Swap with neighbor |
| Super+Alt+Left/Right/Up/Down | Snap top/bottom (Alt+Up/Down) | — | Move into group that way |

Media keys on Novalis use PipeWire and playerctl (volume, mute, mic,
play, next, prev). The screens have no backlight, so brightness is
unbound. The Keychron circle opens notification history, the triangle
opens the update list, and the square opens devices. The light key
is unbound. X opens the session list. The Keychron crop key sends Print. Crop copies a region
and saves it under `~/Pictures/Screenshots`. Shift+crop grabs the
focused window. Ctrl+Shift+crop grabs both screens. Alt+crop is
SysRq, so the kernel keeps it and Hyprland never sees a window
shot on that chord. Delorean uses Omarchy’s matching helpers.
